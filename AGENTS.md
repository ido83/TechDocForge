# TechDocForge project skills

Before acting on a task that matches a skill below, load and follow its instructions. Apply every relevant skill when a task spans multiple areas.

Load the [Caveman skill](.github/skills/caveman/SKILL.md) at the start of each project session and use it by default for user-facing chat. Follow any tone or level of detail the user requests.

| Task | Skill |
| --- | --- |
| Write or review Python code, design classes, or change dependencies | [Python development](.github/skills/techdocforge-python-development/SKILL.md) |
| Write or review code, scripts, configuration, or packaging for security | [Secure code and configuration](.github/skills/techdocforge-secure-code-config/SKILL.md) |
| Work on Markdown preview or Qt document rendering | [Markdown preview](.github/skills/techdocforge-preview-markdown/SKILL.md) |
| Work on Mermaid diagram content, rendering, preview, or export | [Mermaid diagrams](.github/skills/techdocforge-mermaid-diagrams/SKILL.md) |
| Prepare, draft, or open a pull request | [Create a pull request](.github/skills/techdocforge-create-pr/SKILL.md) |
| Work on GitHub Actions CI, dependency or security scans, or linting | [GitHub Actions CI](.github/skills/techdocforge-github-actions-ci/SKILL.md) |

Maintain the full skill instructions in `.github/skills/`. Keep their discovery entries in `.agents/skills/` for Codex and `.claude/skills/` for Claude Code in sync when adding, renaming, or changing a skill's description.
